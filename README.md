# ward-view-web-page
This repository is used to create the web page for WardView App

A static showcase page (Problem, Solution, App Tour, Features, Architecture, Data Flow, Tech Stack) for Ward View. The app's source code is private.

- `index.html`, `styles.css`, `script.js`: the page (no build step)
- `assets/screens/`: desktop (2560×1600) and phone (780×1688) screenshots, taken from a local demo with fictional patient data

To publish: Settings → Pages → Deploy from a branch → `main` / root.
